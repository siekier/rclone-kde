Polityka prywatności

Ta polityka opisuje prywatne użycie Google Drive API przez narzędzie rclone oraz sposób przechowywania danych podczas korzystania z tej konfiguracji OAuth.

Ostatnia aktualizacja: 10 listopada 2026 r.

1. Cel i charakter rozwiązania

„rclone KDE” jest nazwą prywatnej konfiguracji OAuth używanej na komputerze z systemem Linux. Nie jest odrębną usługą internetową, nie udostępnia kont innym osobom i nie świadczy komercyjnej usługi przechowywania danych.

2. Jakie dane mogą być przetwarzane?

Po wyrażeniu zgody przez właściciela konta program rclone może uzyskać dostęp do zawartości Dysku Google, w tym nazw plików i folderów, metadanych oraz treści plików. Jeśli użytkownik przyzna pełny zakres https://www.googleapis.com/auth/drive, obejmuje on możliwość odczytu, tworzenia, zmieniania i usuwania plików.

Dane są wykorzystywane wyłącznie do operacji zleconych przez użytkownika, np. wyświetlenia listy katalogów, otwarcia dokumentu, przesłania lub usunięcia pliku.

3. Przechowywanie i przepływ danych

  • Logowanie OAuth odbywa się z udziałem Google i lokalnie uruchomionego programu rclone.
  • Tokeny autoryzacyjne oraz ustawienia połączenia są przechowywane na komputerze użytkownika w lokalnym pliku konfiguracji rclone, standardowo ~/.config/rclone/rclone.conf.
  • Przy montowaniu Dysku rclone może korzystać z lokalnej pamięci podręcznej i zapisywać tymczasowe kopie odczytywanych lub zmienianych plików, zależnie od ustawień.
  • Właściciel tej strony nie uruchamia osobnego serwera pośredniczącego w transferze danych Google Drive. Transfer plików odbywa się między komputerem użytkownika a usługą Google.

4. Udostępnianie danych

Konfiguracja nie jest przeznaczona do sprzedaży danych, reklam, profilowania ani przekazywania zawartości Dysku Google niezależnym podmiotom. Dane mogą trafiać do lokalnych programów lub usług wybranych przez użytkownika, jeśli ten samodzielnie uruchomi takie operacje. Korzystanie z danych z API Google ogranicza się do opisanych tutaj celów i podlega zasadom Google API Services User Data Policy, w tym odpowiednim wymogom Limited Use.

5. Witryna informacyjna i pliki cookie

Ta witryna jest statyczna: nie zawiera własnych formularzy logowania, skryptów analitycznych, reklam ani mechanizmów śledzących. Jest hostowana przez GitHub Pages. Operator hostingu może przetwarzać podstawowe dane techniczne związane z obsługą żądań HTTP, zgodnie ze swoją polityką prywatności.

6. Cofnięcie zgody i usunięcie dostępu

Zgodę można cofnąć w dowolnym momencie w ustawieniach połączeń konta Google. Lokalny dostęp można dodatkowo usunąć w rclone config, kasując odpowiednie połączenie, a także usuwając niepotrzebną pamięć podręczną. Cofnięcie zgody nie usuwa automatycznie plików uprzednio pobranych na komputer.

7. Kontakt

Projekt jest prowadzony prywatnie przez właściciela profilu GitHub siekier. Pytania dotyczące treści tej strony można zgłaszać przez Issues w repozytorium projektu, o ile ta funkcja jest włączona.
